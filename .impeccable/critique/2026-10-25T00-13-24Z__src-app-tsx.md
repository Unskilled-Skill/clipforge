## Design Specificity Verdict

LLM: the editor is authored for a game clipper (Discord-tier export with quality estimate, numbered kill markers, per-track audio, filmstrip, key legend). The library reads like a generic dark file manager: raw filenames, machine-cased game names, no kills or highlights on cards, "Scan for black" as a top action.
